## 怎么看效果

1. **重启** Spring Boot（改了 `application.yml` 与 Java，必须重启）
2. 登录后台 → **未来植物**
3. 建议顺序：系统总览 → 设备控制（调 LED/泵）→ 历史数据 → 数据管理（预览/导出）

## MQTT 刷屏说明

日志里的 `Connection refused` 是本机 **没有 Mosquitto** 导致的。  
已将默认改为：

```yaml
mqtt.enabled: false
plant.mqtt.enabled: false
```

本地 Mock 开发不再刷屏。真机联调时再改回 `true`，并启动 Broker。
