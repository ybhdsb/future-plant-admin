## 1 引言

### 1.1 目的

本说明书规定未来植物原型系统软件侧的功能范围、数据模型、接口契约与控制指令语义，作为设计实现、联调测试与验收的统一依据。文中字段、枚举与路径均以当前代码库与数据库脚本为准；对尚未实机接入的能力，仍给出完整接口与字段定义，供后续边缘控制器与传感器按契约实现。

### 1.2 范围

**纳入范围**

- 温室环境遥测采集、存储、查询与导出
- 执行器手动控制、定时策略与自动化规则
- 指令审计、运行事件、媒体资产
- 作物表型档案、指标时序、分析任务与数字化展示
- 与平台共用的设备注册、模型库、数据集、用户鉴权
- 平台与边缘之间的 HTTP / MQTT 数据与指令接口
- Web 管理端（Vue SPA）功能与路由

**不纳入范围**

- 机械结构、水路与灯架详细设计
- 供电与配电设计图纸
- RS485 寄存器位级协议正文（由电气另行提供地址表；软件按本说明书的测点键与指令契约消费）
- 联邦学习训练编排、机器人视觉业务的改造规格（仅要求与未来植物业务域隔离）

### 1.3 术语

| 术语 | 定义 |
|------|------|
| `device_key` | 设备稳定唯一标识，字符串，贯穿平台与边缘 |
| 遥测（Telemetry） | 边缘向平台上报的传感器测点数据 |
| 指令（Command） | 平台向边缘下发的控制请求 |
| 执行器（Actuator） | LED、泵、风机、继电器、遮光电机等可控对象 |
| 测点键（metric） | 形如 `air.temperature` 的指标唯一名 |
| 执行器标识（actuator_id） | 形如 `led.ch1`、`pump.water` 的执行器唯一名 |
| Mock | 无实机时由平台模拟遥测与状态，用于软件联调 |

### 1.4 约定

- 时间字段：业务以采样/抓拍时间为准；入库时间用于延迟与审计。数据库时间精度为 `DATETIME(3)`。
- 布尔字段：库中 `TINYINT`，`1` 表示真，`0` 表示假。
- JSON 字段：存 UTF-8 文本，结构见各节说明。
- HTTP 响应方言：未来植物业务接口使用 `{code,message,data}` 且成功码为 `0`；平台鉴权与资源库接口成功码为 `200`，消息键为 `msg`。

## 2 系统概述

### 2.1 系统组成

| 层次 | 说明 |
|------|------|
| 管理端 | Vue SPA，部署于 `/app/`；资源与权限部分页面以内嵌方式复用原有 FreeMarker/Layui 页面 |
| 平台服务 | Spring Boot，默认端口 `8708`，MySQL 持久化 |
| 边缘控制器 | 树莓派 / Jetson 等，负责 RS485 轮询、继电器控制、MQTT 上下行（实机阶段） |
| 消息通道 | MQTT：指令主题前缀 `plant/cmd/`，遥测 `plant/telemetry/#`，回执 `plant/ack/#` |

### 2.2 默认设备

| 项 | 值 |
|------|------|
| 默认 `device_key` | `plant-ctrl-01` |
| 配置项 | `plant.default-device-key` |

### 2.3 建设目标（软件）

1. 环境测点可持续入库并可在管理端展示。
2. 管理端可下发 LED、泵、风机、继电器、相机等指令，并记录审计与状态。
3. 历史曲线、图片记录、CSV/Excel 导出可用。
4. 表型档案与分析任务链路可运行（实机模型可后置接入）。
5. 与既有设备管理、模型库、数据集、用户鉴权共存，业务路由隔离。

## 3 功能需求

### 3.1 运行总览

| 编号 | 需求 | 说明 |
|------|------|------|
| FR-DASH-01 | 看板聚合 | 展示在线状态、关键测点、执行器摘要、近期指令与事件、近时趋势序列 |
| FR-DASH-02 | Mock 开关 | 可启用/关闭指定设备的模拟遥测 |
| FR-DASH-03 | 刷新周期 | 管理端宜按不大于 5 s 的周期拉取看板（与 `plant.mock.interval-ms` 对齐） |

### 3.2 手动控制

| 编号 | 需求 | 说明 |
|------|------|------|
| FR-CTL-01 | LED 八通道 | `led.ch1`～`led.ch8`，亮度 0～100 |
| FR-CTL-02 | LED 定时 | 支持每日窗口与周期开闭两类策略 |
| FR-CTL-03 | 泵与风机等 | 按执行器目录启停；含实机前预留的遮光电机标识 |
| FR-CTL-04 | 自动化规则 | 时间窗、隔日、周期、传感器阈值触发 |
| FR-CTL-05 | 云台与相机 | 支持相机抓拍指令；云台动作指令须写入指令日志并可下发边缘 |
| FR-CTL-06 | 指令查询 | 支持按设备查询指令列表与单条详情 |

### 3.3 历史与导出

| 编号 | 需求 | 说明 |
|------|------|------|
| FR-HIS-01 | 单测点/多测点查询 | 支持时间窗与条数限制 |
| FR-HIS-02 | 分页读取 | `/readings` 分页 |
| FR-HIS-03 | 导出 | CSV 与 Excel；列字段见接口节 |

### 3.4 表型与数字化

| 编号 | 需求 | 说明 |
|------|------|------|
| FR-PH-01 | 植株档案 | 植株编码、穴位、品种、生育期、空间行列 |
| FR-PH-02 | 表型指标 | 株高、叶片数、茎粗、叶面积、SPAD 等时序 |
| FR-PH-03 | 多模态媒体 | RGB/深度/红外等资产登记与访问 |
| FR-PH-04 | 分析任务 | 创建、排队、运行、成功/失败；支持模拟完成以便联调 |
| FR-PH-05 | 数字化展示 | 管理端植株卡片与表型驱动形态参数 |

### 3.5 平台资源与权限

| 编号 | 需求 | 说明 |
|------|------|------|
| FR-RES-01 | 设备管理 | 列表、状态统计、创建部署、心跳、邀请加入 |
| FR-RES-02 | 模型库 | CRUD、文件存储、下载与预览 |
| FR-RES-03 | 数据集 | CRUD、类型筛选、下载与预览 |
| FR-RES-04 | 用户鉴权 | 登录、退出、用户增删改查、管理员标记 |

| air.humidity | %RH | 空气湿度 | 必接 |
| air.co2 | ppm | 二氧化碳 | 宜接 |

| nutrient.ec | mS/cm | 营养液电导率 | 必接 |
| nutrient.do | mg/L | 溶氧 | 宜接 |
| nutrient.level | （自定义） | 液位 | 预留 |

### 6.2 表型测点键

| metric | 单位 | 说明 |
|--------|------|------|
| height_cm | cm | 株高 |

| stem_diameter_mm | mm | 茎粗 |

| spad | （无量纲） | SPAD |

### 6.3 执行器标识与状态

#### 6.3.1 LED

| actuator_id | 说明 |
|-------------|------|
| led.ch1 … led.ch8 | 八通道补光 |

建议 `state_json`：

```json
{ "actuatorId": "led.ch1", "on": true, "brightness": 80 }
```

`brightness`：整数 0～100；`on=false` 时亮度按 0 处理。

#### 6.3.2 目录执行器

| actuator_id | 名称 | 分组 | commandType | 基线实现 |
|-------------|------|------|-------------|----------|
| pump.water | 循环水泵/供液泵 | 供水曝气 | PUMP_SET | 是 |
| pump.oxygen | 氧泵/曝气泵 | 供水曝气 | PUMP_SET | 是 |
| fan.1 | 循环风机 1 | 通风 | FAN_SET | 是 |
| fan.2 | 循环风机 2 | 通风 | FAN_SET | 是 |
| relay.1 | 继电器开关 1 | 通用继电器 | RELAY_SET | 是 |
| relay.2 | 继电器开关 2 | 通用继电器 | RELAY_SET | 是 |
| shade.1 … shade.4 | 遮光电机 1～4 | 遮光 | SHADE_SET | 预留（实机后续） |

开关类建议 `state_json`：

```json
{ "actuatorId": "pump.water", "on": true }
```

相机逻辑标识（出现在载荷中，非目录表主键）：`camera.main`。

### 6.4 指令类型与载荷

边缘订阅主题建议：`plant/cmd/{deviceKey}`。  
平台下发信封：

```json
{
  "schemaVersion": "1.0",
  "deviceKey": "plant-ctrl-01",
  "commandId": "c-123",
  "clientRequestId": "uuid-optional",
  "commandType": "LED_SET",
  "issuedAt": "2026-09-30T12:00:00.000+08:00",
  "payload": {}
}
```

回执主题建议：`plant/ack/{deviceKey}`。回执体：

```json
{
  "commandId": "c-123",
  "status": "ACKED",
  "message": "ok",
  "stateAfter": { "actuatorId": "led.ch1", "on": true, "brightness": 80 }
}
```

`status` 与指令日志一致：`ACKED` / `FAILED`（亦可扩展为与库字段对齐的其他终态）。

#### 6.4.1 `LED_SET`

```json
{
  "channels": [
    { "actuatorId": "led.ch1", "brightness": 80 },
    { "actuatorId": "led.ch2", "brightness": 0 }
  ],
  "reason": "manual"
}
```

#### 6.4.2 `PUMP_SET` / `FAN_SET` / `RELAY_SET` / `SHADE_SET`

```json
{ "actuatorId": "pump.water", "on": true }
```

#### 6.4.3 `CAMERA_CAPTURE`

```json
{ "cameraId": "camera.main", "reason": "manual" }
```

#### 6.4.4 `GIMBAL_MOVE`

```json
{ "action": "UP" }
```

`action` 取值：`UP`、`DOWN`、`LEFT`、`RIGHT`、`HOME`。边缘须实现；平台记录指令并下发。
