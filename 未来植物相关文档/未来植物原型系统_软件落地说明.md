# 未来植物原型系统软件落地说明

对应需求文档：`未来植物原型系统_软件需求规格说明书.md`（文档编号 FP-SRS-2026）

## 1 与规格说明书的对应关系

| 规格章节 | 当前工程落地 |
|----------|--------------|
| 运行总览 / 看板 | Vue SPA `/app/dashboard`；接口 `GET /plant/api/dashboard` |
| LED / 执行器 / 相机 / 指令日志 | `/app/control/*`；指令 `POST /plant/api/commands` |
| 历史与导出 | `/app/history`、`/app/data`；`/plant/api/metrics*`、`/export/telemetry` |
| 表型与数字化 | `/app/phenotype/*`；`/plant/api/phenotype/*` |
| 设备 / 模型 / 数据集 / 鉴权 | `/app/devices` 等；对应 `/device/api`、`/api/models`、`/api/datasets`、`/auths` |
| 数据表 | `sql/plant_v1_schema.sql` + JPA 实体 |
| MQTT 契约 | 配置见 `application.yml`；默认本地关闭 Broker 连接 |

字段、枚举与载荷以规格说明书第 4～6 章为准，本文不重复罗列。

## 2 本地运行要点

1. 启动 Spring Boot（默认端口 `8708`）。
2. 访问 `/app/login` 进入管理端；默认设备键 `plant-ctrl-01`。
3. 本地无 MQTT Broker 时保持：

```yaml
mqtt.enabled: false
plant.mqtt.enabled: false
```

实机联调时启用 MQTT，并按规格说明书第 6 章主题与载荷实现边缘端。
