# 未来植物原型系统 — 技术栈与工具说明

文档性质：纯技术 / 工具盘点（不含业务需求与验收细则）。  
对应工程：`future-plant-admin`  
关联文档：`未来植物原型系统_软件落地说明.md`、各硬件对接说明。

## 1 总体技术架构

```
浏览器
  ├─ Vue 3 SPA（主路径 /app/*）
  └─ FreeMarker 遗留页（设备 / 模型库 / 数据集 / 权限，经 SPA 嵌入）
        │  HTTP / WebSocket
        ▼
Spring Boot 2.2.2（Java 8）:8708
        │
        ├── MySQL（库名 rail_traffic）
        ├── MQTT（可选，默认关闭）→ 边缘控制器 / plant-edge 模拟
        └── HTTP 网关（可选）→ 摄像头 :8080 / LED :8090
```

交付形态：Maven 可执行应用 + Vite 构建产物内嵌至 `src/main/resources/static/app/`。无 Docker / 无容器编排。

| 层级 | 技术选型 | 版本 / 备注 |

| 运行时 | JDK | 1.8 |
| 后端框架 | Spring Boot | 2.2.2.RELEASE |
| Web / WS | spring-boot-starter-web / websocket | 随 Boot |

## 7 架构特征（技术视角）

1. **双前端**：Vue 3 SPA（`/app`）为主；设备 / 库 / 权限仍走 FreeMarker，由 `LegacyEmbedView` 嵌入。  
2. **双设备通路**：实验室 **HTTP 网关**（相机 / LED）与 **MQTT 边缘控制器** 并存，均可关闭，靠 Mock / 本地库演示。  
3. **双持久化栈**：植物与设备主路径 **JPA**；用户等旧模块 **MyBatis**。  
4. **单体交付**：无容器化；前端构建产物打进后端静态资源。  
5. **自定义鉴权**：拦截器 + Session，非 Spring Security。
